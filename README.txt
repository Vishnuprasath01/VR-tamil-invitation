1. தற்போதைய website repository-இலிருந்து assets/photos/ folder-ஐயும் assets/wedding-music.m4a கோப்பையும் இதே folder-இல் copy செய்யவும்.
2. GitHub-ல் புதிய Public repository உருவாக்கவும் (உதாரணம்: vishnu-rithanya-tamil-wedding).
3. index.html, styles.css, script.js, assets folder ஆகியவற்றை repository-யின் root-இல் upload செய்யவும்.
4. Settings > Pages > Deploy from a branch > main > /(root) > Save தேர்வு செய்யவும்.
5. GitHub Pages வெளியிடும் வரை காத்திருக்கவும்.
